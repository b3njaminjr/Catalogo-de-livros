📚 Sistema de Ordenação de Catálogo de Livros

Repositório destinado ao desenvolvimento da atividade prática da disciplina (Estrutura de Dados e Algoritmos), cujo objetivo é implementar um sistema completo de gerenciamento e ordenação de um catálogo de livros integrando um backend em linguagem C a uma interface gráfica.

🎯 Sobre o Desafio

O sistema foi projetado para permitir a ordenação de um conjunto de livros utilizando dois critérios fundamentais:

Nome do Livro (Ordem alfabética)

Preço (Ordem numérica)

Além disso, cada critério suporta tanto a ordem crescente quanto a decrescente.

🛠️ Especificações Técnicas

Backend (Lógica): Implementado obrigatoriamente em Linguagem C, contendo os algoritmos de ordenação e manipulação dos dados.

Frontend (Interface Gráfica): Conectado ao backend em C para proporcionar uma experiência interativa aos usuários.

Uso de IA: O uso de Inteligência Artificial foi permitido e incentivado no desenvolvimento e integração do frontend e auxílio técnico.

📊 Critérios de Avaliação

O projeto será avaliado com base nos seguintes pesos:

Implementação e Correção do Algoritmo em C (50%): Funcionamento correto da ordenação por nome e preço nos sentidos crescente e decrescente.

Domínio do Algoritmo na Apresentação (30%): Clareza da equipe ao explicar a lógica implementada e a manipulação dos dados.

Integração C e Interface (20%): Comunicação bem-sucedida de ponta a ponta entre a interface e o backend.
